# WindySync

Move your working setup from one Windows PC to another. One side offers, the other picks, only the picks travel, end to end
encrypted, and an AI agent finishes the setup on the new machine.

WindySync is the Windows member of a family: [MacySync](https://macysync.vercel.app) (Mac to Mac),
[LinySync](https://github.com/Ege-BULUT/LinySync) (Linux to Linux) and
[AnySync](https://github.com/Ege-BULUT/AnySync) (any of them to any of them). It runs AnySync's engine with Windows on both ends:
only Windows devices are listed and accepted.

Status: early. `windysync` opens the window; `windysync --scan`, `--give <id>`, `--accept` and `--id` do the same from a
terminal. See [docs/DESIGN.md](docs/DESIGN.md).

## Download

The Windows build is on the [releases page](https://github.com/Ege-BULUT/WindySync/releases): `windysync-windows-x64.exe`.
