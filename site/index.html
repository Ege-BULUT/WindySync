Your next PC, already yours.

Windy~Sync moves one Windows PC's setup to another: editor settings, SSH and GnuPG keys, the PowerShell profile, bookmarks, your folders and the lists of what winget and Scoop installed. Files go straight PC to PC, end-to-end encrypted, and a brief tells your AI agent what is left.

How it works

GitHub introduces them, the devices talk direct

Your PCs meet in a private GitHub repo of yours. The files never go there: they travel from one PC to the other.

01

Any PC sends, any PC receives

Like a remote desktop app: pick the other PC, then send or receive. It holds for that transfer only.

02

From one PC to the next

01

Find

The PCs on your account show up as desktops and laptops. Click one to pick it.

02

Ask

Choose to send or to receive. The other device asks its owner to approve.

03

Pick

The sender offers a tree of what it has; you tick what the new PC takes.

04

Move

Only the picks travel, straight across and encrypted. A cut connection asks again for what is missing.

05

Finish

Each item lands in its place, and GOAL.md tells your AI agent what is left to do.

03

It lands where Windows keeps it

Each item knows its place under the new PC's own user folders, whatever the user is called there.

ItemLands atThen

Whatever was already in place is kept next to it as .before-windysync. When the user folder has another name on the new PC (C:\Users\ege to C:\Users\ege.b), the brief lists the configs that still name the old one.

Features

What makes the move painless

One small app on both PCs.

EITHER WAY

Send or receive, every time

No fixed sender. Either PC sends to or takes from the other, chosen per transfer.

WINDOWS PATHS

Lands where Windows keeps it

%APPDATA%, %LOCALAPPDATA% and Documents are read on each PC, so a new user name changes nothing.

PICK

A tree you tick

Groups, then items. Ticking a group ticks everything in it, and only the ticked ones travel.

DIRECT

PC to PC, not via a cloud

Files go over your network. GitHub only carries who is who and the sealed keys.

SEALED

End-to-end encrypted

Offers, picks and keys are sealed to each PC's own key; files stream under XChaCha20-Poly1305.

BRIEF

Your agent finishes it

GOAL.md says what landed where, and hands over the winget and Scoop lists to install from.

On the move

What moves, and what stays

WindySync moves the settings and files that make a PC yours, and says plainly what it leaves for a fresh start.

What moves

  • Files: Desktop, Documents, Downloads, Pictures, Music and Videos, each top-level item on its own. Folders rebuilt from source, like node_modules, target and .venv, stay behind.
  • Shell and git: git config, SSH and GnuPG keys, the PowerShell profile.
  • Editors and terminals: VS Code, Cursor, Zed, Wave.
  • Notes, browsers, AI tools: Obsidian's vault list, bookmarks of Edge, Chrome, Brave and Chromium, Claude Code, Codex.
  • Lists of installed tools: winget, Scoop, npm, cargo, pipx, VS Code and Cursor extensions.

What stays, and why

  • The programs themselves: they are installed again from the winget and Scoop lists, not copied.
  • Passwords saved in browsers: Windows seals them with DPAPI for the old PC's account. Use the browser's own sync or its password export.
  • Windows settings, the registry and the PC's identity: a Tailscale node, remote desktop ids and the like.
  • Logins: AI tools and apps are signed in again on the new PC.
In the repo

Only the handshake lives on GitHub.

you/windysync-bus/           # private
├── devices/
│   ├── 7f3a2c91.json    # name, system, look, public key
│   └── c04e19b7.json
├── requests/            # send or receive, to approve
└── transfers/
    └── 20261126-1605_7f3a2c91_c04e19b7/
        ├── session.json # progress
        ├── offer.sealed # what the sender offers
        ├── picks.sealed # what the receiver takes
        └── key.sealed   # stream key and address

Never on GitHub

  • Your files: they go from PC to PC
  • Anything readable about what you move: offers and picks are sealed
  • Your GitHub sign in: WindySync asks the GitHub CLI for it each time
  • Anything you leave unticked
